# 후기 UI 확인 안내

## 개발용 미리보기

개발 서버 실행 후 `http://localhost:3000/history/preview`에서 확인합니다. 포트가 다르면 실제 개발 서버 포트로 바꿉니다. Next.js 개발 리소스의 호스트 검사를 위해 localhost를 사용합니다.

- 모든 글·작성자·날짜는 명확히 표시한 개발용 데모입니다. 사진 예시는 브랜드 로고입니다.
- 실제 회원으로 로그인한 것처럼 처리하지 않습니다. 폼은 서버 저장 함수를 호출하지 않고, 삭제 확인도 실제 삭제 요청을 보내지 않습니다.
- 운영 빌드에서는 페이지가 404이며 운영 `/history`에는 미리보기 링크가 표시되지 않습니다.
- 새 글 폼, 수정 폼, 카드 상세 및 삭제 확인을 DB 없이 확인할 수 있습니다.

## 이번 UI 작업에서 확인한 내용

- 카테고리/두 줄 제목/네 줄 본문/작성자·날짜 정렬, 데스크톱 3열 및 모바일 1열.
- 제목 120자·본문 10,000자 안내, 필수값과 공백 입력 검사.
- JPG·PNG·WebP 원본 장당 5MB 이하를 선택해 긴 변 최대 1600px·저장 장당 1MB 이하로 자동 처리합니다. 기존 사진 포함 최대 3장, 새 사진 미리보기·개별 취소, 기존 사진 삭제 예정·복원을 유지합니다. 새 제한의 실제 업로드는 로컬 버킷 1MB 설정 승인·적용 후 별도 검증합니다.
- 작성 중 닫기/취소/Escape 시 유실 확인, 계속 작성 시 입력·사진 유지. 새로고침/탭 닫기에는 브라우저 기본 경고를 요청합니다. 경고 표시 여부는 브라우저 정책에 따릅니다. 임시 자동 저장 기능은 아닙니다.
- 모달 내부 Tab 순환, Escape, 종료 후 초점 복귀, 입력 레이블.
- 실제 저장 실패 시 입력 유지. 저장 성공은 기존 서버의 DB 저장 성공 응답이 있을 때만 표시합니다.
- 빈 목록·연결 오류에서도 필터와 등록 버튼은 유지합니다.

## 검증 결과

- `npm run lint`: 통과.
- `npm run build -- --webpack`: 통과 (TypeScript 포함).
- 환경변수 없는 임시 복사본의 Webpack 개발 서버에서 1280px·390px Chrome으로 입력/사진 검증, 미리보기·취소, 유실 확인, 수정 기존 값, 삭제 확인, Tab/Escape/초점 복귀, 가로 넘침 없음을 검증했습니다.
- 데모 점검 동안 등록·업로드·수정·삭제 네트워크 요청은 0건이었습니다.
- 운영 빌드 `/history/preview`의 HTTP 404 및 응답 내 데모 글·표시명 미포함을 확인했습니다.

## 여전히 연동이 필요한 내용

이전 UI 검사 이후 로컬 DB 테이블·RLS를 적용하고 A/B·anon DB 컨텍스트의 후기 테이블 권한은 검증했습니다. 로그인 후 `/history` 자동 복귀는 미구현입니다. 새 사진 정책의 실제 업로드와 Storage 권한은 로컬 버킷 1MB 설정 승인·적용 후 별도로 검증합니다. 이번 사진 개선은 공통 인증을 수정하지 않으며 SQL 초안의 버킷 제한만 변경합니다. 운영 DB·Storage는 미적용 상태입니다.

## 사진 처리 개선 추가 검사

- 사진·서버 입력 검증 및 signed URL 회귀 자동 테스트 21개 통과.
- Chrome에서 EXIF 방향을 포함한 약 3.5MB JPEG의 최대 1600px·1MB 이하 처리, 원본 EXIF 제거, 투명도, JPEG/PNG 대체를 확인했습니다. Safari 실기기는 별도 확인 대상입니다.
- 별도 개발 미리보기 1280px·390px에서 압축 후 미리보기·첨부 취소·처리 중 저장 차단·5MB/3장 제한·Escape 유실 확인과 계속 작성 시 첨부 유지를 확인했습니다. Supabase 및 변경 요청은 0건이었습니다.
