# 공개 홈페이지 디자인

Miro 참고 원문: `design-md/miro/DESIGN.md`.

## 적용 범위
- 한국어 `/`, 영어 `/en` 및 소개·스터디/이벤트·언어교환·게시판·히스토리의 한·영 페이지.
- 큰 제목, 넉넉한 여백, 둥근 카드·pill 버튼, 상단 현재 메뉴 표시, 공통 헤더·푸터.
- 말모임 노란색 `#fbbc18`, 청록색 `#087f8c`, 원본 로고와 슬로건 유지.
- 기존 글꼴 유지. Miro의 전용 글꼴과 검정 CTA 대신 말모임 브랜드 적용.
- 홈페이지 본문 전용 CSS와 공개 사이트 공통 CSS를 구분하고 `.public-site`로 범위를 제한.
- 상세 페이지의 이동 경로와 관련 메뉴는 실제 기존 경로로 연결.
- 내용이 없는 페이지는 기존 준비 중 안내 유지. 임의 운영 사실이나 데이터 생성 없음.
- 어드민·인증·9기 신청·할로윈 랜딩·DB·환경변수·패키지 변경 없음.

## 검토 및 배포
대표 시안 승인 후 공개 사이트의 나머지 메뉴로 확대했다.
미배포 9기 신청 변경과 분리된 `codex/home-design-preview` 브랜치와 PR #13을 사용한다.
고정 작업 브랜치는 `feat/season9-landing`이며 유지한다.

## 확인
- lint, TypeScript 및 운영 build: PR 검증 결과에 기록.
- 로컬 PC와 모바일 390px에서 한·영 화면 및 메뉴 열기·이동 확인.
- 상세 10개 경로의 페이지 제목과 관련 링크 4개, 모바일 가로 넘침 없음 확인.
- 영어 상세 페이지 1024px 및 320px 가로 넘침 없음 확인.
- 원본 로고와 슬로건 유지 확인.
- 실제 로그인·관리자 권한·로그아웃 테스트는 미검증. 인증 관련 파일 변경 없음.
