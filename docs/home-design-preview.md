# 홈페이지 디자인 시안

Miro 참고 원문: `design-md/miro/DESIGN.md`.

## 적용 범위
- 한국어 `/`, 영어 `/en`의 홈페이지 본문만 변경.
- 큰 제목, 넉넉한 여백, 둥근 카드와 pill 버튼 적용.
- 말모임 노란색 `#fbbc18`, 청록색 `#087f8c`, 원본 로고와 슬로건 유지.
- 기존 글꼴 유지. Miro의 전용 글꼴과 검정 CTA 대신 말모임 브랜드 적용.
- 전용 `public-home-design` 범위 CSS로 헤더·상세 페이지·어드민·행사·인증과 분리.
- 소개 및 스터디·이벤트 링크는 실제 기존 경로로 이동.

## 검토 및 배포
대표 화면의 시안 검토 단계이며 사용자 확인 전 main 병합과 운영 배포를 진행하지 않는다.
미배포 9기 신청 변경과 분리된 preview 브랜치로 검토한다.

## 확인
- lint, TypeScript 검사 통과.
- 로컬 PC 1280px 및 모바일 390px 한국어·영어 화면 확인.
- 모바일 메뉴 열기 및 한·영 전환, 영어 이벤트 페이지 이동 확인.
- 모바일 가로 넘침 없음. 원본 로고와 슬로건 유지 확인.
- 실제 로그인·관리자 권한 테스트는 미검증. 인증 관련 파일 변경 없음.
- 운영 build 결과는 PR 검증 기록에 기재.
