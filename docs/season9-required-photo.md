# 9기 활동 사진 활용 동의 필수

- 한·영 신청서 사진 동의 체크박스에 required와 필수 표시를 적용한다. 미리 체크하거나 자동 동의하지 않는다. 다음 기수 모집 안내 수신은 선택으로 유지한다.
- 서버는 photo_consent=on 없이는 저장 RPC와 전환을 호출하지 않는다. DB는 JSON boolean true만 허용하며 누락·false·null·문자열 true를 거부한다.
- SQL050을 앱 배포 전에 적용한다. 기존 접수 함수의 동의/버전 부분만 수정해 모집 일정·중복·요청 제한·프로필 검증을 보존한다. 직접 내부 함수 실행 권한은 열지 않는다.
- 새 안내 버전은 season9-2026-10-22-photo-required-v2. 기존 열린 양식의 v1 요청도 명시적인 사진 동의가 있을 때만 허용하되 새 접수는 v2와 최신 안내 스냅샷으로 저장한다. 기존 신청의 동의 여부·안내 스냅샷은 수정하지 않는다.
- DB 통합 검증은 supabase/tests/season9_required_photo.sql. 가상 신청과 알림 큐 쓰기는 모두 rollback하고 실제 문자·Meta 전환은 만들지 않는다.

## 검증 (2026-10-22)

- 관련 테스트 15개, ESLint, TypeScript 통과. DB 통합 테스트 PASS 후 테스트 변경 전체 rollback. SQL050 운영 적용 성공. 대상 행사 한 건과 내부 UPDATE가 행 잠금인 것을 읽기 전용으로 확인하고, 마이그레이션에도 동일한 조건을 추가했다.
