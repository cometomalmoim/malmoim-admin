# 대시보드 참여 분석

- 이벤트 등록 버튼과 운영 바로가기는 제목 아래 같은 행의 상단을 맞춘다. 좁은 화면은 세로 배치.
- 상단: 전체 운영 이벤트(기존 범위 유지), 30일 내 예정, 전체 이벤트 참여율.
- 예정 일정 다음의 진행·일정 확인 목록은 접어서 기본 화면을 줄인다.
- 하단: 최근 5개 이벤트 참여율 가로 막대 + 참여자 요약(실제 참여자 수, 1개 이벤트/2개 이상 재참여 비중). 회차 세부는 펼쳐서 확인.

## 지표 구분

이벤트 참여율 = 지난 날짜 회차의 출석 연인원 / 참가 확정 연인원 × 100. 이벤트별 비율의 단순 평균이 아니다. 오늘과 미래 회차·테스트·삭제 이벤트·날짜 없는 과거 출석은 제외. 출석 미입력은 분모에 포함하고 ‘잠정’으로 표시한다. 확정자가 없으면 0%가 아니라 ‘집계 전’. 회차별 확정 인원은 현재의 운영 기록 기준이며 당시 명단 스냅샷은 아니다.

이벤트별 비교는 각 이벤트의 지난 회차를 합산해 최근 회차 날짜순으로 정렬한다. 서로 다른 이벤트는 비교 막대, 같은 이벤트의 상세는 날짜별 회차 막대로 표시. 첫 화면 최대 5개 이벤트, 나머지는 전체 회차 현황 링크로 이동한다.

참여자 요약은 기존 event_person_totals의 실제 참석 이력 기준. 동일인 연결 후 서로 다른 이벤트에 두 번 이상 참석한 사람은 재참여자. 같은 이벤트 여러 회차는 한 번으로 계산한다. 테스트 제외, 보존된 과거/삭제 이벤트 이력 포함. 미연결 기록은 이 인원 수에 반영되지 않는다. 연인원 출석률과 고유 참여자 재참여율은 서로 다른 지표다.

추후 마케팅 지표 후보: 유입경로별 신청 수, 유입경로별 실제 참석 전환, 신규/재참여자 추이. 방문 수 수집 없이 방문→신청 전환율을 계산하지 않는다. 광고비 기록 없이 신청당 비용을 추정하지 않는다. 광고 효과와 시스템 개선 효과를 구분한다.

이번 변경은 기존 관리자 전용 집계 뷰 조회만 추가한다. DB 구조·신청·납부·문자·수료증 규칙은 바꾸지 않는다. 연락처를 대시보드 분석용으로 조회하지 않는다.

검증: participation-rate.test.mjs의 가중 집계·0분모·이벤트 그룹·동일인 지표·한국 날짜 경계와 기존 event-lifecycle.test.mjs 실행. 실제 데이터가 없으면 운영 그래프의 값 있는 상태는 미검증으로 남긴다.
