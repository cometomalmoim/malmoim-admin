# 9기 신청 폼 화면

메타 인스턴트 폼에서 착안한 모바일 중심의 5단계 입력 화면. 말모임 노란 CTA와 청록색 선택 표시를 유지한다. 한국어와 영어를 위아래 계층으로 표시하고, 모바일에서는 단일 흰 화면, 데스크톱에서는 최대 폭 640px의 카드로 표시한다.

- 전용 스타일: src/components/season9/application-design.css (s9-apply-site 범위)
- 선택 항목은 전체 카드 클릭 가능. 기본 체크박스 20px 및 키보드·포커스 유지.
- 이전/다음/제출 버튼은 신청서 하단 sticky 영역. 최종 단계에서만 제출 버튼 표시.
- 입력 필드 name/value, 서버 저장, 접수 상태, 개인정보 문구와 동의 필수 여부는 유지.
- 검증: lint 오류 0(기존 suggestions.ts 경고 2), TypeScript 통과, 별도 검증 worktree 운영 빌드 종료 코드 0. 모바일 390px 가로 넘침 없음. 5단계 이동과 선택 유지, 마지막 동의·제출 버튼 확인.
- 실제 신청 저장/문자 발송 재시험은 하지 않음. 운영 데이터에 테스트 신청을 생성하지 않음.
