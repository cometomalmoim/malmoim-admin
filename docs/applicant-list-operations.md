# 전체 신청자관리: 작은 화면과 선택 삭제

- 전체 목록은 페이지당 10명, 이벤트별 목록은 기존 25명을 유지한다. 전체 목록의 상단 안내는 접고 검색 필터·표를 작게 표시하며 표 내부 스크롤을 제공한다.
- 매체·캠페인은 작은 전체 표에서는 숨기고 상세 창에서 확인한다. 이름·연락처 등 상세 수정과 상태 직접 변경은 유지한다.
- 체크박스는 현재 페이지에서만 선택하며 `source + id`로 구분한다. 필터·페이지·원본 버전이 변경되면 선택을 초기화한다.
- 선택 삭제 전 확인 창을 표시한다. 실제 원본 삭제가 아니라 관리자 목록에서 숨기는 작업이며 삭제된 신청자에서 선택 복원한다. 원본 신청·납부·출석·수료증 이력은 보존한다.
- 관리자만 archive RPC를 실행할 수 있다. 이벤트를 고정 순서로 잠근 뒤 신청 revision과 archive revision을 모두 검사하며, 모든 대상이 유효할 때만 일괄 적용한다. 감사 기록도 동일 트랜잭션에 저장한다.
- 삭제된 신청자는 활성 신청자 목록·이벤트 접수 집계·문자 대상 조회에서 제외한다. 실제 참석 이력은 유지한다.
- 같은 이벤트의 전화번호 중복은 기존 관리 RPC가 국가번호·공백·하이픈을 정규화하여 판정한다. 다른 행사에 재신청하는 것은 허용한다. 삭제된 신청도 기존 기록이 있으므로 재등록 대신 복원한다.
- 중복 결과는 저장하지 않고 `이미 등록하였습니다.`를 빨간색 모달로 안내한다. 입력 내용은 유지한다.
- `024_application_archive.sql` 적용 후 배포한다. 기존 012~020의 팀원 SQL은 수정하거나 다시 적용하지 않는다.
