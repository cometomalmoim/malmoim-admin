# 공식 홈페이지 메인 개편 검증

대상: `/`와 `/en`의 공통 `PublicHome`. Next.js 16.4 / React 19의 기존 PublicFrame, 헤더·계정·언어 전환을 그대로 사용. 새 DB 변경이나 계정 설정 변경 없음.

## 구성과 콘텐츠 관리

슬로건 → 소개 → 정규 세션 → 4가지 활동 → 한국인/외국인 참여 안내 → 현재 프로그램 → 사진 갤러리 → 참여·문의 안내, 8개 영역으로 구성.

`src/lib/public-home-content.ts`에 사진 경로·크기·한영 대체 설명, 활동 소개, 참여 대상, 문의 채널, 프로그램 카드 제목·이미지·설명·링크·노출 여부를 관리한다. 다음 기수에는 `homePrograms`를 교체한다. 모집 표시는 기존 `season9.intakeEnabled`와 `closesAt`를 기반으로 클라이언트에서 확인하며, 마감 시각부터 ‘프로그램 안내’로 바뀐다. DB gate를 새로 조회하거나 실제 접수 가능성을 보장하는 로직은 추가하지 않았으며, 최종 신청 가능 여부는 기존 9기 신청 페이지가 결정한다.

정규 세션은 사용자 제공 ‘6주, 주 2회 운영’을 사용. 기존 9기 코드에서 목요일·토요일, 참여자 희망 요일 주 1회임을 확인해 함께 안내한다. 특별 행사/파티/축제/MT는 별도 활동이라고 명시한다. 그 밖의 장소·기간·인원·후기·만족도는 추가하지 않았다.

## 실제 연결

- 소개/활동/프로그램: `#mh-about`, `#mh-activities`, `#mh-programs`
- 정규 세션 및 9기 카드: 한국어 `/season9`, 영어 `/season9/en`
- 스터디·이벤트: `/events`, `/en/events`
- 히스토리: `/history`, `/en/history`
- 문의: 기존 운영 채널 `https://www.instagram.com/cometomalmoim/`
- 메뉴 및 로그인 경로: 기존 헤더 그대로, 새 상세 경로 없음

## 사진 검토 및 남은 확인 사항

앞서 사용자가 제공한 사진 38장과 기존 로컬 히스토리/소개 사진을 전체 검토. `photos.json`에 선택 원본과 변환 결과 기록. 동일 페이지에서 중복 없이 8장 사용. 최대 1600px WebP, 총 약 1.9MB. 첫 화면 사진만 preload, 나머지는 Next Image 지연 로드 및 반응형 sizes. 이미지에 고정 크기 자르기를 적용하지 않아 전체 장면과 얼굴을 보존한다.

대화/정규 활동/야외 단체사진은 본문에 사용. 파티·축제 부스·MT로 확정할 수 있는 사진은 없어 해당 3개 활동은 타이포그래피 그래픽으로 안내하고, 식사/스파클러/만들기 사진은 일반 갤러리에만 사용했다. 해당 활동의 확인된 현장 사진이 생기면 교체할 수 있다. 미제공 사진을 만들거나 외부 스톡을 넣지 않았다.

## 검증

- 변경 파일 ESLint, `git diff --check` 통과.
- 기존 신청·성별·Meta 전환 회귀 검사와 모집 종료 경계/노출 설정 검사: 총 28개 통과.
- `npm run build -- --webpack`: 컴파일·TypeScript·62개 정적 경로 생성 성공. 기본 Turbopack 빌드는 실행 환경의 로컬 포트 생성 EPERM으로 실패하여 Webpack으로 검증.
- 로컬 프로덕션 서버에서 기존 한영 메뉴·로그인·9기 포함 16개 경로 HTTP 200 확인.
- 390 / 768 / 1440px에서 문서 폭과 화면 폭 일치, 수평 넘침 없음. 모바일 메뉴 열기/이벤트 이동, 언어 전환, 소개 앵커, 영어 9기 링크 이동 확인.
- 선택 이미지 로드, 콘솔 오류 없음. 원래 로그인 세션 발급, 신청 제출, SMS/전환 실전송은 수행하지 않음.
- 한국어 모바일/PC 및 영어 PC 화면을 같은 폴더에 저장.

기존 의존성 Next.js 16.4에서 보안 업데이트 권고가 표시됨. 이번 메인 UI 개편에는 프레임워크 버전 변경을 포함하지 않았다.


## 2026-10-27 사진 교체

사용자가 새로 지정한 10장을 첫 화면 → 소개 → 야외행사 → 파티 → 축제·부스 → MT → 9기 모집 카드 → 갤러리 1~3 순서로 적용. 정규 세션은 추가로 지정한 11번째 사진을 별도 적용했다. 한영 대체 설명과 갤러리 캡션, 공유 미리보기 사진도 장면에 맞게 변경. 기존 사진 분류 미확정에 따른 그래픽 3개는 실제 지정 사진으로 교체되었다. 이미지 전체 비율을 유지하며 PC 활동 사진은 contain으로 얼굴/장면을 보존한다. 기존 9기 신청 페이지 파일은 변경하지 않았다.
