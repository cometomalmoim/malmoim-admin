# A조 이벤트 정보와 수정 분리

1. 문제사항: 운영 현황과 상세 정보·수정 동선이 같은 개요에 혼재했다.
2. 개선 경험: 개요는 현황·운영 바로가기, 이벤트 정보는 상세 조회, 수정은 정보 화면의 버튼으로 분리했다.
3. 진행 과정: 기존 변경과 main 내용 일치 확인 및 stash 보존 → 최신 main 반영 → 기존 상세 영역 이동 → 기존 편집 재사용.
4. 측정: 처리 시간·오류 감소는 미측정. lint/build 및 배포 검증 결과는 최종 보고에 별도 기록한다.
5. 어려움과 해결: 이미 원격 커밋된 로컬 변경을 중복 커밋하지 않도록 내용 일치를 확인하고 복구 stash를 유지했다.
6. AI 활용: 기존 기능과 보호 경계를 유지하면서 조회와 편집 동선을 분리했다.
7. 포트폴리오: 이벤트 운영 현황·상세 조회·편집 역할을 구분해 관리 화면의 탐색 구조를 개선했습니다.
8. 자소서: 운영 화면의 정보 혼재를 발견하고 상세 조회 탭과 수정 버튼으로 동선을 구분했습니다. 기존 조회·편집 기능을 재사용하고 검증 결과와 미검증 항목을 구분했습니다.
