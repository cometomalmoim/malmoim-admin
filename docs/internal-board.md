# 내부 게시판

`/admin/internal-board`는 관리자만 이용하는 게시글·댓글 공간입니다.

## DB 적용

기존 마이그레이션 이후 `supabase/021_internal_board.sql`을 Supabase SQL Editor 또는 프로젝트의 DB 배포 절차로 적용합니다. 이 작업에서는 운영 DB를 변경하지 않았습니다. 적용 전에는 게시판이 명시적인 로드 실패 안내를 표시합니다.

게시글 및 댓글은 관리자에게만 조회가 허용되며, 직접 테이블 변경은 차단됩니다. `manage_internal_board` RPC가 현재 로그인 사용자 ID로 작성자를 설정하고 수정·삭제·고정을 작성자에게만 허용합니다. 변경 시 `updated_at` 비교와 행 잠금으로 오래된 화면의 덮어쓰기를 거부합니다. 삭제는 댓글도 함께 삭제합니다.

## 동작

- 공지이면서 고정된 글만 최상단에 정렬하며, 나머지는 작성일 내림차순입니다.
- 공지를 일반 카테고리로 바꾸면 고정이 해제됩니다.
- 검색은 제목·본문·작성자에 적용되며 카테고리 및 고정 필터와 동시에 작동합니다. 필터 패널을 접어도 선택한 조건은 유지됩니다.
- 작성·수정은 우측 패널에서 수행하며, 삭제는 같은 패널의 확인 버튼으로 확정합니다.
- 검색은 현재 로드한 게시글에 즉시 적용됩니다. 다른 사용자의 변경을 가져오려면 새로고침합니다.

## 확장 필터와 화면 비율

좌측 목록과 우측 상세는 12열 기준 5:7 비율이며 좁은 화면에서는 세로 배치합니다. 작성 기간은 한국 시간 기준 시작일·종료일을 모두 포함합니다. 최근 1주일은 오늘 포함 7일, 최근 1달은 전월 같은 날짜부터 오늘까지이며 전월에 같은 날짜가 없으면 말일을 사용합니다. 날짜 한쪽만 입력해도 필터링됩니다.

작성자 이름 입력은 게시글 목록을 즉시 검색하며, 내가 쓴 글만 보기 옵션은 로그인 사용자 ID로 필터링합니다. 두 조건을 동시에 사용할 수 있습니다. 필터는 카테고리·작성자 검색, 기간·퀵 선택, 보기 옵션·초기화의 3행으로 구성합니다. 모든 조건은 검색어·고정 공지 조건과 함께 적용됩니다. 초기화는 검색어와 모든 필터를 비웁니다.

아이디어 카테고리 저장을 위해 `supabase/021_internal_board.sql` 이후 `supabase/022_board_idea_category.sql`을 적용해야 합니다. 기존 시스템 카테고리도 계속 지원합니다.

## 댓글 수정·삭제와 이미지 첨부

`023_board_comments_images.sql`을 022 이후 적용합니다. 비공개 `board-images` 버킷과 게시글 이미지 경로, 댓글 수정 버전을 추가합니다. 운영 DB에는 자동 적용하지 않았습니다.

댓글 수정·삭제는 본인에게만 표시되고 DB에서도 작성자 및 `updated_at`을 검사합니다. 삭제는 인라인 확인 후 처리하며 실패하면 입력을 유지합니다.

게시글에 JPG·PNG·WebP 이미지를 최대 4장 첨부할 수 있습니다. 파일당 3MB, 새 파일 합계 4MB로 제한하여 기존 Server Action 5MB 한도 안에서 처리합니다. 원본 파일을 재인코딩하지 않고 MIME과 파일 헤더를 확인합니다. 폼에서 선택한 이미지를 미리보기로 확인하고 저장 전 삭제할 수 있습니다. 기존 이미지는 수정 시 유지/삭제할 수 있습니다.

이미지는 사용자 ID별 경로로 업로드되며 RPC에서 소유권과 저장소 객체 존재를 확인합니다. 저장 실패 시 신규 업로드를 정리하고 저장 성공 시 제거된 이미지를 Storage에서 삭제합니다. 삭제 정리가 일시적으로 실패한 객체는 비공개로 남을 수 있으며, 상세 이미지 API는 현재 게시글에 연결된 이미지만 반환합니다. 운영 환경의 실제 업로드/다운로드 확인은 마이그레이션 적용 후 수행해야 합니다.

## 목록 페이지 이동

검색·필터 및 고정 공지 정렬 후 10개씩 표시합니다. 검색어나 필터 조건을 바꾸면 1페이지로 돌아갑니다. 이전·숫자·다음 버튼으로 이동하며 첫/마지막 페이지에서는 해당 이동 버튼을 비활성화합니다. 페이지가 많으면 중간 번호를 생략하고 현재 페이지 주변을 표시합니다. 게시글 저장·삭제·고정 변경 후에는 1페이지로 돌아갑니다.
