# 이벤트 운영 흐름

- 이벤트 관리(`/admin/events`)는 이벤트 이름을 선택하는 목록이다. 등록 버튼은 유지한다.
- 이름 선택은 기존 `/admin/events/[slug]/overview`를 운영 홈으로 재사용한다.
- 운영 홈의 정보·신청자/선발·참여/출석·공개 모집 페이지 진입점을 사용한다.
- 공개 모집 페이지는 기존 할로윈·9기 연결만 제공한다. 나머지는 미연결로 표시한다.
- 참여·출석 목록은 해당 이벤트의 신청자와 기존 `event_participation`을 source + application_id로 연결한다. 이름·연락처 검색과 25건 페이지 이동을 제공한다.
- 사람 연결 전은 미참석으로 취급하지 않는다. 참가 확정·출석 저장은 기존 개인별 관리 화면을 재사용한다. 새로운 쓰기 함수나 DB 변경은 없다.
- 전체 신청자관리와 참여이력관리는 여러 이벤트를 조회하는 독립 메뉴로 유지한다.
- 메시징·수료증 화면과 사이드바 메뉴는 변경하지 않는다. 새 사이드바 운영 홈을 중복 생성하지 않는다.
- 기존 신청자 직접 추가·상세 수정·상태 직접 변경과 자료실 URL을 유지한다.
