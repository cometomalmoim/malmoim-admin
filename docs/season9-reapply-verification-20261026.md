# 9기 전화번호 재지원

- 원인: compact 신청 RPC가 관리자 보관(삭제) 여부와 관계없이 동일 연락처를 거부했다.
- 053은 전화번호에 의한 새 제출 차단만 해제한다. 기존 제출 UUID의 재시도는 동일 신청 하나로 처리하고, 기존 UUID로 내용을 바꾸면 거부한다. Instagram 정책, 공개 접수 스위치, 동의·형식 검증, 1분/일일 제한과 RLS는 유지한다.
- 기존 함수 본문 해시가 저장소 052와 같음을 운영 DB에서 확인한 뒤 적용했다. 053은 예상된 기존/신규 해시만 허용하여 다른 구현을 임의 덮어쓰지 않는다.
- 운영 DB 검증: 동일 번호 신규 제출 2건, 동일 제출 재시도 중복 없음, 첫 가상 신청 보관 후 동일 번호 신규 제출 성공을 트랜잭션 안에서 확인했다.
- 전체 롤백 후 remaining_test_applications=0, remaining_test_sms=0, unchanged_intake={open:true} 확인. 실제 문자 발송 없음. 실사용자의 신청·납부·출석 기록 수정 없음.
- 랜딩은 포스터와 모집 핵심 내용 → 지난 활동/프로그램/참여 안내 → FAQ·문의 → 하단 신청서 순서로 재배치한다. 입력 항목과 동의 문구는 유지한다.
