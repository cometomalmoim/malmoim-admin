# 일일참여와 1:1 언어교환 운영

## 신청 경로
- 일일참여: `/daily`, `/en/daily`
- 언어교환: `/exchange`, `/en/exchange`
- 신청 후 개인 확인 링크에서 상태·운영진 안내 확인 및 취소
- 자동 문자·결제·환불·상대 연락처 공유는 실행하지 않음

## 일일참여
9기 목요일 18:30–21:00, 토요일 13:00–15:30 (한국시간), 각 6회이며 1회 12,000원이다. 인원 제한과 정원 표시는 없다. 날짜별 접수 마감 기본값은 모임 시작 시각이며 운영진은 개별 회차 신청을 닫을 수 있다.

어드민 `/admin/daily-participation`에서 날짜 추가·접수 열기/닫기와 신청자 상태·공개 안내를 관리한다. 확정·납부·취소 및 환불 관련 조건은 신청자에게 별도로 안내한다.

## 1:1 언어교환
어드민 `/admin/matching`에서 제공/학습 언어, 각 언어 수준, 한국시간 기준 가능 시간, 온라인/오프라인 및 지역, 관심사를 확인한다. 서로 제공·학습할 언어가 맞는지 먼저 확인하고 시간·만남 방식을 검토한다. 양쪽 참여 의사를 확인한 뒤 상태를 확정하고 개인 링크의 안내에 첫 만남 정보를 남긴다. 상대 연락처 공유 전 양쪽 동의를 확인한다.

첫 만남 권장안: 각 언어 25분 + 마무리 10분. 상대가 없으면 대기 상태로 안내하며 재검토 요청을 받을 수 있다. 매칭 결과를 보장하거나 공개 프로필을 제공하지 않는다.

## 저장·권한
새 community 전용 테이블과 RPC를 사용한다. 기존 이벤트 신청·참여 이력·회원·문자 테이블은 변경하지 않는다. 익명 사용자는 신청 테이블에 직접 접근할 수 없다. 확인 토큰은 256비트 난수이며 DB에는 SHA-256 해시만 저장한다. 토큰은 확인 링크의 fragment에만 포함한다.

개인 링크를 분실하면 운영진이 신청자의 제공 연락처로 직접 안내한다. 토큰 복구·재발급은 현재 제공하지 않는다. 접수 정보에는 보관 검토일(접수 3개월 후)이 기록되며 운영진이 보관 필요성과 파기를 관리한다. 자동 파기 작업은 포함하지 않는다.

## 적용·검증
- `supabase/054_community_participation.sql`: 신규 테이블, RLS, 접수·조회·취소·관리 RPC
- `supabase/055_season9_daily_sessions.sql`: 승인된 12회차 일정
- 운영 DB에는 위 내용과 동등한 migration 3개(초기 구성, 일정, 전화번호 정규화 검증)를 적용함
- `supabase/tests/community_participation.sql`: 트랜잭션 내 가상 데이터만 사용 후 전체 롤백
- `node --test tests/participation-requests.test.mjs tests/public-home-programs.test.mjs tests/public-language-preference.test.mjs tests/season9-landing.test.mjs`
- `npx next build --webpack`

공개 접수 RPC는 의도적으로 SECURITY DEFINER를 사용하며 빈 search_path, 입력 검증, 최소 반환값, 비밀 토큰 및 관리자 재검증으로 접근 범위를 제한한다. 일반 사용자·익명 사용자의 관리자 상태 변경 및 테이블 직접 읽기는 허용하지 않는다.
