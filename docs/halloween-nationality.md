# 할로윈 신청 국적 입력

- 한·영 공개 신청서에서 이름 다음에 필수 국적·성별 입력을 제공한다. 공백 제거, 최대 100자, 공개 접수에서 빈 국적·성별은 거부한다. 기존 출생연도·동의·전화번호 검증은 유지한다.
- SQL 047을 먼저 적용한 뒤 앱을 배포한다. DB 적용 전 앱을 배포하면 새 RPC가 없어 신청이 실패하므로 PR은 적용 확인까지 병합하지 않는다.
- 새 RPC는 기존 출생연도 접수 RPC에 검증·저장을 위임하고 같은 transaction에서 국적을 저장한다. 이벤트 row lock으로 중복 요청을 직렬화하고 동일 submission UUID의 국적 변경 재시도를 거부한다.
- 기존 응답은 null로 유지한다. 기존 공개 저장 함수는 유지하고 권한을 확대하지 않는다. 관리자 view는 원래 응답의 국적을 보여주되 기존 관리자 수정값을 우선한다. 국적 검색·한국인/외국인 필터가 기존 view를 통해 작동한다.
- 향후 신청의 개인정보 안내에 선택 국적을 추가하고 버전을 갱신한다. 기존 신청의 안내 스냅샷은 변경하지 않는다. 모집 상태·마감·정원은 변경하지 않는다.
- Meta 전환에는 국적을 포함하지 않는다.
- SQL 통합 검증: supabase/tests/halloween_nationality.sql. 관리자 전용 기존 가상 이벤트에서만 실행하고 rollback한다. 실제 운영 신청이나 SMS·전환 이벤트를 생성하지 않는다.

## 검증 결과 (2026-10-21)

- Supabase SQL047 적용 성공. 기존 안내 버전과 접수 열림을 사전 확인했다.
- DB 통합 테스트 PASS: 국적 저장·선택 미입력·길이 제한·같은 제출 재시도·국적 변경 재시도 차단·관리자 수정 우선·한국인/외국인 분류·익명 조회와 관리자 테스트 차단. 테스트 쓰기 전체 rollback.
- 관련 Node 테스트 18개, ESLint와 TypeScript 통과. Meta 이벤트 매개변수에 국적을 추가하지 않음 확인.

## 국적·성별 필수 변경 (2026-10-21)

- 할로윈 공개 접수의 국적과 성별은 모두 필수다. 성별은 남성·여성·기타 중 선택한다. 관리자 테스트와 기존 신청 기록의 누락 값은 유지한다.
- SQL048로 gender 컬럼·관리자 조회·새 필수 접수 RPC·새 안내 버전을 먼저 적용한다. 앱 배포 후 SQL049로 필수 검증을 우회하는 기존 공개 RPC 직접 호출을 닫는다. 내부 security definer 호출은 유지한다.
- 관리자 상세 화면에서 성별을 조회한다. 개인정보는 Meta 전환 매개변수에 추가하지 않는다.
- 통합 테스트: supabase/tests/halloween_required_profile.sql, 관리자 가상 이벤트에서 수행 후 전부 rollback.

- SQL048 운영 적용 및 DB 통합 테스트 PASS 확인. 필수 누락·잘못된 성별 차단과 관리자 성별 조회를 확인했고 테스트 쓰기 전체를 롤백했다. SQL049는 앱 배포 확인 후 적용한다.
