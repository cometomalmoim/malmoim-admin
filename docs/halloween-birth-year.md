# 현재 기준 (2026-10-18 추가 요청)

공개 할로윈 신청은 출생연도 필수이며 1990~2007년생만 허용합니다. 한·영 입력 필드, 서버 액션, DB 038에서 검증합니다. 기존 응답은 소급 수정하지 않고 관리자 가상 테스트는 기존 선택 입력을 유지합니다. 038은 개인정보 안내를 필수 항목으로 변경하고 버전을 갱신합니다.

이하 내용은 037 최초 도입 당시 기록입니다.

# 할로윈 출생연도 선택 입력

- 한·영 공통 신청서에서 이름·연락처 다음에 출생연도(YYYY) 선택 항목. 나이나 생년월일 전체를 받지 않는다.
- 미입력 허용. 서버와 DB 제출 함수에서 1900~올해(KST) 검증. 입력 오류/저장 실패 시 입력값 유지.
- 원본은 event_registration_responses.birth_year에 저장. 기존 관리자 뷰에 반영하며 관리자의 명시적 수정/비우기가 우선한다. 기존 신청의 원본값을 추정하거나 채우지 않는다.
- 기존 UTM·중복 전화번호·접수 기간·정원·개인정보 동의 검사는 기존 함수로 유지. 같은 제출 ID의 재시도는 같은 출생연도만 허용하며 기존 원본값을 덮어쓰지 않는다.
- 037 SQL은 기존 접수/게시 설정을 바꾸지 않고 현재 개인정보 안내에 선택 출생연도를 추가한다. 기존 보유기간과 과거 snapshot 보존. 안내 변경 시 클라이언트는 입력을 유지한 채 새 안내를 불러와 다시 동의받는다.
- SQL 037은 단독 1회 실행. 사전 테스트는 마지막 COMMIT 제외 후 supabase/tests/halloween_birth_year.sql을 이어 실행해 가상 신청과 DDL을 롤백한다.
- 관리자 가상 제출은 SMS worker를 실행하지 않는다. 실제 신청 알림의 기존 동작은 유지. 공개 실제 신청으로 검증하지 않는다.

검증: registration.test.mjs 5개(선택/연도 경계/유효성 포함), SQL 가상 저장·관리자 조회·수정 우선·원본 보존·UTM·재시도·익명 권한. 브라우저 확인은 배포 후 별도 수행.
